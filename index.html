work and intelligence

Personio’s Assistant and app frame evolved as one system: a persistent workspace for AI, navigation, and everyday actions.

The Assistant and product competed for the same space.

The overlay obscured navigation and actions—and in Analytics, the report template it was meant to help create.

Global search was limited to Home; profile and inbox access lacked prominence. AI and frame supported one workflow from disconnected layers.

Interviews traced the friction across the frame.

April–June 2026 sessions surfaced three failures: lost navigation during employee changes, a reset Analytics conversation, and a hidden report template.

One participant also expected workflows in a persistent inbox. The shared need was to keep work and assistance in reach.

The frame makes core actions easier to reach.

Global search moves beyond Home into the header; the employee profile and inbox entry points gain prominence there too.

These persistent controls establish orientation while the Assistant stays available beside the active product page.

One interaction model had to serve the whole workflow.

Overlay, page-level AI, and an embedded panel were compared. The overlay kept its interruptions; page-level AI could not carry a conversation across the product.

The embedded Assistant offered continuity, with the frame and page adapting around it.

The surface responds to available space.

Wide viewports use a resizable side panel beside the page. Narrow screens switch to full-screen; /assistant supports immersive work.

The same conversation is intended to persist between modes.

Conversation state and page context are separate contracts.

The thread persists across routes; the current URL can inform page-aware prompts.

Context payload, permissions, unsaved state, and fallbacks require technical and security validation. Persistent chat does not mean unrestricted page access.

Shared patterns support distinct AI surfaces.

The Assistant can host specialist widgets; focused tools such as summaries can stay within product pages.

Shared UI patterns provide consistency while product teams own domain data and agents. The technical brief proposes routing requests through Amazon Bedrock.

The redesign joins the frame and Assistant.

Global search, employee profile, inbox, navigation, and AI share a persistent product frame.

Proposed measures include CSAT, weekly use, context loss, mode changes, task completion, support, and performance. Delivery and impact remain unverified.
